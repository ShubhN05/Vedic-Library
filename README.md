# BOOKS

A library of India's great original texts. Here you can find the **PDFs of each book, in both Hindi and English**, collected in one place.

> हिन्दी: यहाँ भारत के सभी प्रमुख मूल ग्रंथों की PDF, हिन्दी और अंग्रेज़ी दोनों संस्करणों में, एक ही जगह मिलती हैं।

## What you will find here

- The original texts: the epics, the four Vedas, the Upanishads, the Gita, the Dharmashastras, the classical sciences and all 18 Mahapuranas.
- Every book has its own folder, and every folder has a **Hindi** version and an **English** version.
- Books are added one at a time. A folder that has only a README is waiting for its files.

## How the library is arranged

```
BOOKS/
├── E01-Mahabharata/
│   ├── hindi/      <- Hindi PDFs
│   └── english/    <- English PDFs
├── 07-Bhagavad-Gita/
│   ├── hindi/
│   └── english/
└── P03-Vishnu-Purana/
    ├── hindi/
    └── english/
```

| Prefix | Meaning |
|---|---|
| `E` | The two great epics |
| `01`-`20` | Vedas, Upanishads, Gita, Shastras and other classical texts |
| `P` | The 18 Mahapuranas |

## How to read a book

1. Open the folder of the book you want.
2. Open `hindi` or `english`, whichever language you prefer.
3. Click the PDF, then use the download button or read it in the browser.
