# BOOKS

A library of India's great original texts. Here you can find the **PDFs of each book, in both Hindi and English**, collected in one place.

> हिन्दी: यहाँ भारत के सभी प्रमुख मूल ग्रंथों की PDF, हिन्दी और अंग्रेज़ी दोनों संस्करणों में, एक ही जगह मिलती हैं।

## Which books are ready?

Books are added one at a time. Open a book that says **Complete** or **Partly**. A book that says **Coming soon** has an empty folder for now.

- **Complete** means the whole book is there in that language.
- **Partly** means some parts are there and the rest are on the way (for example, 14 of 18 parvas).
- **Coming soon** means nothing has been added yet.

## How to read a book

1. Open the folder of the book you want.
2. Open `hindi` or `english`, whichever language you prefer.
3. Click the PDF, then use the download button or read it in the browser.

## Why this library exists

This library is only for people who find it hard to get these books in Hindi and English. The aim is to make them easy to find and read in one place.

I do not earn any money from this project, and I never will. It is free for everyone.

If you like a book, please support the real publishers and authors. Buy the original book from them so their work can continue.
