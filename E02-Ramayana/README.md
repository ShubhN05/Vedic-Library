# Ramayana

The Valmiki Ramayana in **English**, one PDF for each of its 7 kandas (books). The Hindi version is coming soon.

> हिन्दी: वाल्मीकि रामायण के सातों काण्ड अंग्रेज़ी में उपलब्ध हैं। हिन्दी संस्करण जल्द आएगा।

## About these books

- **The text:** the Valmiki Ramayana, the original Sanskrit epic in 7 kandas.
- **The English translation:** by **Bibek Debroy**, *The Valmiki Ramayana* (Penguin Books India, 3 volumes, 2017).
- **Layout:** each PDF is one kanda. They are not the 3 Debroy volumes. This makes each book easy to find and open.

## Complete book

**Note:** the file starting with `00` is the **complete Ramayana in one book**. It is not a different book from `01`, `02` and the others. Each of `01` to `07` has only **one kanda**, and `00` has **all 7 kandas together**. So if you want the whole Ramayana, download `00`. If you want a single kanda, download its own file.
